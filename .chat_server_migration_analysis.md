# Chat server-write migration analysis

- Clients read `chat_rooms/{roomId}` and ordered `messages` streams directly for realtime UI.
- Client write paths existed in main chat, request creation, invoice/signing sharing,
  admin chat, and admin report handling.
- Messages may contain text, attachment data, document IDs, request linkage, and system flags.
- Migration: clients call `sendChatMessage`; it atomically creates the message, room summary,
  unread count, and notification. Clients retain participant reads and `isRead` updates.
